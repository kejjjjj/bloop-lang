A bloop program is a file of statements that run from top to bottom, with functions, closures and modules for
structure. The syntax is JavaScript's, the rules are stricter: there's no implicit conversion between strings and
numbers, only booleans, numbers and undefined can be conditions, functions take exactly as many arguments as they have
parameters, and reading a property or an element that isn't there is an error.
