bloop is a small scripting language for embedding in C++ programs: applications, tools, anything that wants
to be scripted. It looks like JavaScript, but it's strict: mistakes stop the script with an error that says where,
instead of being papered over.

```
fn greet(name) {
	return `Hello, ${name}!`;
}

const names = ["Ada", "Grace"];
for (const name : names)
	std.console.log(greet(name));
```
```output
Hello, Ada!
Hello, Grace!
```
