---
abs, min, max, clamp and sign keep their argument's type (an int stays an int). floor, ceil, round and trunc give an
int, so the result can index an array; so does idiv, whole numbers divided as whole numbers (the `/` operator always
gives a double). Everything else gives a double, with the usual IEEE results (`sqrt(-1)` is nan).

# std.math.idiv {=std.math.idiv}

decl std.math.idiv(a, b)  // a and b: ints or uints

`a` divided by `b` as whole numbers, rounded towards zero: `std.math.idiv(7, 2)` is `3`, `std.math.idiv(-7, 2)` is
`-3`. Two ints give an int, two uints a uint, an int and a uint an int. Dividing by zero is a runtime error
(`std.math.idiv: division by 0`), and so is a double (`std.math.trunc(a / b)` divides doubles that way).

```
const middle = std.math.idiv(std.length(items), 2);   // an index
const rows = std.math.idiv(count + per_row - 1, per_row);
```

# Random numbers {=std.math.random, std.math.random_int, std.math.seed}

decl std.math.random() -> double  // in [0, 1)
decl std.math.random_int(low, high) -> int  // in [low, high], both included
decl std.math.seed(seed)

Every script has its own generator. The same seed gives the same numbers again: a script that has to repeat a run
(a replay, a generated world) seeds it. The program running the script may seed it first; otherwise every run is
different.

```
std.math.seed(7);
const first = std.math.random_int(1, 6);
std.math.seed(7);
std.console.log(first == std.math.random_int(1, 6));
```
```output
true
```
