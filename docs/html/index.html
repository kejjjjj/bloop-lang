bloop reference

bloop is a small scripting language for embedding in C++ programs: applications, tools, anything that wants to be scripted. It looks like JavaScript, but it's strict: mistakes stop the script with an error that says where, instead of being papered over.

fn greet(name) {
	return `Hello, ${name}!`;
}

const names = ["Ada", "Grace"];
for (const name : names)
	std.console.log(greet(name));
Output:
Hello, Ada!
Hello, Grace!
Language
  • Basic concepts: source files, comments, identifiers, literals
  • Types: undefined, booleans, numbers, strings, arrays, objects
  • Variables: let, const, scope
  • Operators
  • Conditions: what can be true or false
  • Control flow: if, while, for, ranged for
  • Functions, lambdas and closures
  • Strings and template strings
  • Objects and arrays
  • Modules: import and export
  • Exceptions: throw, try, catch
  • Errors: compile errors and runtime errors
  • Coroutines and tasks
Standard library
  • std: what's in it, std.length, permissions
  • std.console: printing
  • std.array: array functions
  • std.string: string functions
  • std.object: object functions
  • std.math: numbers
  • std.json: JSON text
  • std.time: clocks
  • std.task: waiting without blocking
  • std.coroutine: coroutines
  • std.fs: files (when allowed)
  • std.process: arguments, exit (when allowed)
Using bloop
  • Embedding: running scripts from C++
  • The standalone interpreter: bloop file.bloop [arguments...] runs a file; std.process.args() has the arguments
