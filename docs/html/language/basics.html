Source files

A bloop program is a text file (UTF-8, usually ending in .bloop) of statements. They run from top to bottom; a return at the top level ends the file, and its value is what the file returns to whoever ran it. The functions that a file declares can be used before their declaration (see hoisting).

std.console.log("first");
std.console.log(add(1, 2));     // add is declared further down

fn add(a, b) {
	return a + b;
}
Output:
first
3

Statements

A statement ends with a semicolon, except the ones that end with a block: fn, if, while, for, try. A block is statements between braces, and it can't be empty: { } is a compile error. The body of an if, a while or a for can also be a single statement without braces.

if (count > 10)
	std.console.log("a lot");

while (count > 0) {
	count--;
}

Comments

// starts a comment that goes to the end of the line, /* */ one that can span lines. Comments don't nest.

Identifiers

Names of variables, functions and parameters: letters, digits and underscores, not starting with a digit. They're case sensitive. A name can't be one of the keywords, and it can't be declared twice where both are visible: an inner block or a function inside another can't declare a name that the outer one already has (see shadowing).

Keywords

fn let const if else while for return break continue try catch throw import export typeof true false undefined

from has a meaning in an import statement only.
