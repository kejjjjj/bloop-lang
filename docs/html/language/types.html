Types

Every value has one of these types. A variable can hold any of them, and change from one to another. The names are the ones that error messages use.

undefined

The value that means nothing: a variable declared without a value, a missing optional argument of a standard function, a function that ends without returning a value, std.array.pop() of an empty array. undefined is a condition that is false.

Booleans

true and false, what comparisons and the logical operators give. In arithmetic a boolean counts as 1 or 0 (true + 1 is 2).

Numbers

int

The usual number: a 64-bit signed integer. Integer literals are ints. Arithmetic on ints stays int (+, -, *, %), and going past the largest or smallest int wraps around; but / always gives a double: 7 / 2 is 3.5. std.math.idiv divides as whole numbers (std.math.idiv(7, 2) is 3).

uint

A 64-bit unsigned integer, written with a u after the number (5u). Subtracting past zero wraps around to the largest values, and a uint can't be negated.

double

A 64-bit floating point number (IEEE 754): literals with a decimal point, and the results of arithmetic that has a double in it. Dividing by zero gives inf (or -inf, or nan for 0 / 0), no error.

When an operator gets an int and a double, the int is converted to a double first: 1 + 2.5 is 3.5. Between an int and a uint, the uint becomes an int.

Strings

Text, as a sequence of bytes (UTF-8 for anything that isn't ASCII): indexes and lengths count bytes. Strings never change: every function that "changes" one returns a new string. See Strings.

Arrays and objects

Arrays and objects are shared, not copied: assigning one to another variable, passing it to a function or putting it in another array gives that place the same array, and a change through any of them is seen through all of them. == compares them by identity: two different arrays with the same elements aren't equal.

const a = [1, 2];
const b = a;
std.array.push(b, 3);
std.console.log(a, " ", a == b, " ", [1] == [1]);
Output:
[ 1, 2, 3 ] true false

See Arrays and Objects.

Functions

Functions are values: they can be stored in variables, arrays and objects, passed to other functions and returned from them. See Functions.

Handles

A program that runs a script can give it handles: values that stand for something of the program's (a file, a window, a task). A script keeps them, compares them (==: the same thing) and passes them back to the program's functions, but can't look inside them or make one. They print as their type and a number, like task#2. A handle can be an object's key (objects): counts[door] = 1.
