Arithmetic

OperatorWhat it does
a + baddition; two strings: joined (see strings)
a - bsubtraction
a * bmultiplication
a / bdivision, always a double: 7 / 2 is 3.5, 1 / 0 is inf, 0 / 0 nan (whole numbers: std.math.idiv)
a % bthe remainder (the sign of a): 7 % 3 is 1, -7 % 3 is -1; on doubles too
-anegation (not on a uint)
++a, a++adds one: before (the new value) or after (the old value)
--a, a--subtracts one

An int and a double: the int becomes a double. A boolean counts as 0 or 1. Anything else (a string with a number, two arrays) is a runtime error: there's no implicit conversion, std.string.from and std.string.parse_int convert.

Comparison

OperatorWhat it does
a == b, a != bequal: numbers by value across types (1 == 1.0, 1 == true), strings by content, arrays, objects and functions by identity
a === b, a !== bstrictly equal: the same type and equal (1 === 1.0 is false)
a < b, a <= b, a > b, a >= bnumbers only

Comparing a number with a string (1 == "1") is a runtime error, not false. Strings can't be compared with <.

Logic

OperatorWhat it does
a && btrue when both are; b isn't evaluated when a is false
a || btrue when either is; b isn't evaluated when a is true
!anot
c ? a : ba when c is true, else b (only the one chosen is evaluated)

The operands are conditions, and the result of &&, || and ! is always a boolean: undefined || 5 is true, not 5.

Assignment

a = b assigns and gives the value assigned. a += b, -=, *=, /=, %=, &=, |=, ^=, <<=, >>= combine an operator with assignment. The left side is a variable (not a constant), an element a[i] or a property o.p / o["p"].

typeof

typeof value gives the name of the value's type, as a string:

Valuetypeof gives
undefined"undefined"
true, false"boolean"
1, 1u, 1.5"int", "uint", "double" (there's no "number")
"text""string"
[1, 2]"array"
{ a: 1 }"object"
a function, a lambda, a standard function"function"
a coroutine"coroutine"
a handleits type's name, like "task"

It's a prefix operator: typeof a.b[0] is the type of a.b[0], and typeof x == "int" is (typeof x) == "int".

fn describe(value) {
	const type = typeof value;
	if (type == "int" || type == "uint" || type == "double")
		return "number";
	return type;
}

std.console.log(describe(1.5), ", ", describe([1]), ", ", describe(describe));
Output:
number, array, function

Calls, elements, properties

f(a, b) calls a function, a[i] is an element of an array or a byte of a string, o.name and o["name"] a property of an object (std.array, std.string... are objects too: std.array.push).
