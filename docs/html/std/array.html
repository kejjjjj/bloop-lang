std.array

Standard library std.console std.array std.string std.object std.math std.json std.time std.task std.coroutine std.fs std.process

Functions for arrays. The ones that change the array change it in place (arrays are shared: everybody who has it sees the change); the ones that make something new say so.

Callbacks get (element, index); a callback with fewer parameters gets only the first ones: (x) => x * 2 works.

std.array.push

std.array.push(array, values...) -> int

Adds the values to the end, in order. Returns the new length.

const list = [1];
std.array.push(list, 2, 3);
std.console.log(list);
Output:
[ 1, 2, 3 ]

std.array.push_front

std.array.push_front(array, values...) -> int

Adds the values to the front (in the given order: push_front(a, 1, 2) makes a start with 1, 2). Returns the new length.

std.array.resize

std.array.resize(array, count, fill) -> arrayfill is optional

Makes the array count long: cut at the end, or new elements set to fill (undefined if left out). Returns the array.

std.array.fill

std.array.fill(array, value, start, end) -> arraystart and end are optional

Sets the elements from start up to (not including) end to value: all of them without start and end. Returns the array.

std.array.slice

std.array.slice(array, start, end) -> arraystart and end are optional

A new array with the elements from start up to (not including) end. Negative indexes count from the end (-1 is the last); out of range ones are clamped. Without end: to the end; without both: a copy.

std.console.log(std.array.slice([1, 2, 3, 4], 1, 3), " ", std.array.slice([1, 2, 3, 4], -2));
Output:
[ 2, 3 ] [ 3, 4 ]

std.array.find

std.array.find(array, callback)
std.array.find_last(array, callback)

The first (last) element for which callback(element, index) is true, or undefined.

const people = [{ name: "Ada", age: 36 }, { name: "Grace", age: 85 }];
const old = std.array.find(people, (p) => p.age > 50);
std.console.log(old.name);
Output:
Grace

std.array.accumulate

std.array.accumulate(array, callback, initial)initial is optional

Folds the array into one value (JavaScript's reduce): the result starts as initial and becomes callback(result, element, index) for every element. Without initial, it starts as the first element (and the callback isn't called for it).

std.console.log(std.array.accumulate([1, 2, 3, 4], (sum, x) => sum + x, 0));
Output:
10

std.array.sort

std.array.sort(array, comparator) -> arraycomparator is optional

Sorts in place and returns the array. Without a comparator the elements must be all numbers or all strings, and go in ascending order. With one, comparator(a, b) returns a negative number when a goes before b, a positive one when after, 0 when it doesn't matter. The sort is stable (equal elements keep their order).

const words = ["pear", "fig", "banana"];
std.array.sort(words, (a, b) => std.length(a) - std.length(b));
std.console.log(words);
Output:
[ fig, pear, banana ]
