std.object

Standard library std.console std.array std.string std.object std.math std.json std.time std.task std.coroutine std.fs std.process

Functions for objects. Keys are strings or handles, and lists come in the order the properties were added.

std.object.keys

std.object.keys(object) -> array
std.object.values(object) -> array

Every property's name (or value), in order.

const scores = { ada: 3, grace: 5 };
std.console.log(std.object.keys(scores), " ", std.object.values(scores));
Output:
[ ada, grace ] [ 3, 5 ]

std.object.has

std.object.has(object, key) -> boolean

Whether the object has the property: reading one that it doesn't have (o.key) is a runtime error.

std.object.get

std.object.get(object, key)

The property's value, or undefined when it isn't there.

std.object.set

std.object.set(object, key, value)

Adds or changes the property, returns the value. The same as object[key] = value.

std.object.remove

std.object.remove(object, key) -> boolean

Removes the property; returns whether it was there.
