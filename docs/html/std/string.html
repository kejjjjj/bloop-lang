std.string.substring

std.string.substring(s, start, end) -> stringstart and end are optional

The bytes from start up to (not including) end. Negative indexes count from the end; out of range ones are clamped. Without end: to the end.

std.console.log(std.string.substring("bloop", 1, 3), " ", std.string.substring("bloop", -2));
Output:
lo op

std.string.find

std.string.find(s, part, from) -> intfrom is optional
std.string.find_last(s, part, from) -> intfrom is optional

The index of the first occurrence of part at or after from (0 if left out), or -1. find_last: the last one that starts at or before from (anywhere if left out).

std.string.split

std.string.split(s, separator) -> array

The parts between every separator, as an array of strings (empty ones too: "a,,b" gives three). An empty separator splits into single bytes.

std.console.log(std.string.split("a,b,,c", ","), " ", std.string.split("hey", ""));
Output:
[ a, b, , c ] [ h, e, y ]

std.string.from

std.string.from(value) -> string

Any value as text: what std.console.log prints for it. The way to put a number into a string with +.

const count = 3;
std.console.log("count: " + std.string.from(count));
Output:
count: 3
