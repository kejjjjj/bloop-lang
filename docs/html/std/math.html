std.math

Standard library std.console std.array std.string std.object std.math std.json std.time std.task std.coroutine std.fs std.process

abs, min, max, clamp and sign keep their argument's type (an int stays an int). floor, ceil, round and trunc give an int, so the result can index an array. Everything else gives a double, with the usual IEEE results (sqrt(-1) is nan).

std.math.seed(seed)

Every script has its own generator. The same seed gives the same numbers again: a script that has to repeat a run (a replay, a generated world) seeds it. The program running the script may seed it first; otherwise every run is different.

std.math.seed(7);
const first = std.math.random_int(1, 6);
std.math.seed(7);
std.console.log(first == std.math.random_int(1, 6));
