std.fs

Standard library std.console std.array std.string std.object std.math std.json std.time std.task std.coroutine std.fs std.process

Files and directories. Only when the program running the script allows it (a permission): the standalone interpreter does. Paths are relative to the working directory, or to a root directory the program sets (and then a path outside of it is a runtime error). What can fail on its own (a missing file, no access) returns undefined or false.

std.fs.make_dir("out");
std.fs.write("out/notes.txt", "first line\n");
std.fs.append("out/notes.txt", "second line\n");
std.console.log(std.fs.read("out/notes.txt"), std.fs.list("out"));
Output:
first line
second line
[ notes.txt ]
