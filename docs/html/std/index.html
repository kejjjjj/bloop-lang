Standard library

Standard library std.console std.array std.string std.object std.math std.json std.time std.task std.coroutine std.fs std.process

std is a global in every script: an object whose properties are the library's modules (std.array, std.string...) and a few functions of its own. It's always there, no import needed.

Modules

ModuleWhat's in it
std.consoleprinting
std.arrayadding, removing, searching, transforming and sorting arrays
std.stringsearching, splitting, converting strings
std.objectan object's keys and values, properties that may not be there
std.mathnumber functions, random numbers
std.jsonJSON text to values and back
std.timeclocks
std.taskfunctions that wait without blocking
std.coroutinefunctions that pause and continue
std.fsfiles and directories (only when the program running the script allows it)
std.processarguments, environment, exit (only when allowed)

Permissions

The parts of the library that reach outside of the script (std.fs, std.process, std.time.sleep) exist only when the program running the script allows them; otherwise they're missing (using them is an error: the property doesn't exist). The standalone interpreter allows everything; a program running untrusted scripts would usually allow none of them.

std.length

std.length(value) -> int
value-a string, an array or an object

The length of a string (in bytes), the number of elements of an array, the number of properties of an object.

std.console.log(std.length("héllo"), " ", std.length([1, 2, 3]), " ", std.length({ a: 1 }));
Output:
6 3 1

std.gc_major, std.gc_minor

std.gc_major()a full collection
std.gc_minor()the young objects only

Runs the garbage collector now. Memory is collected by itself; these are for testing and measuring.
