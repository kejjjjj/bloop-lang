std.process

Standard library std.console std.array std.string std.object std.math std.json std.time std.task std.coroutine std.fs std.process

The program the script runs in. Only when the program allows it (a permission): the standalone interpreter does.

std.process.args

std.process.args() -> array

The arguments the program gave the script: for the standalone interpreter, what comes after the script's path (bloop build.bloop src out gives ["src", "out"]).

std.process.env

The value of an environment variable, or undefined when it isn't set.

std.process.exit

std.process.exit(code)code is optional

Ends the script now. The standalone interpreter exits with code (0 if it's left out).
